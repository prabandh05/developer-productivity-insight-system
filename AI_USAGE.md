# AI Usage Documentation

## Overview
AI was used as a supporting tool during development to improve understanding and speed up certain parts of the workflow. The overall system design, logic, and implementation decisions were done independently.

---
## Tools Used

- Chatgpt 
-AntiGravity

## Where AI Was Used

### 1. Problem Understanding
AI was used to clarify the definitions of key metrics such as cycle time, lead time, bug rate, and deployment frequency.

---

### 2. Development Support
AI assisted in:
- Reviewing code structure
- Suggesting minor improvements
- Helping debug small issues during development

---

### 3. Optimization
AI was occasionally used to identify small optimizations and cleaner ways to structure functions and API calls.

---

## Key Point

AI was used only as a guidance tool.  
All core logic, data processing, metric calculations, and system design decisions were implemented and understood independently.

---

## Conclusion

The final system reflects my own understanding of the problem, with AI used only to support learning and development efficiency.
